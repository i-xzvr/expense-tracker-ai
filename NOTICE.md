# Source and upstream components

Expense Tracker V4 is a cumulative local bookkeeping application developed around exercises and architecture concepts from **Claude Code: Software Engineering with Generative AI Agents** (Vanderbilt University / Jules White). Course review documents summarize concepts and link to their original pages. No course transcripts, videos, assessment submissions, or account sessions are distributed.

Application dependencies retain their upstream licenses as recorded in package lockfiles and installed package notices. The bundled Noto Sans font is distributed with its [SIL Open Font License](public/fonts/OFL.txt). Git, Node, Ollama, model weights and Claude are downloaded from their upstream sources by setup; their own terms remain applicable. The repository does not bundle their executable archives or model weights.

No project-wide license grant has been selected for this repository. Public visibility provides access to the source for review and retention; it does not replace an explicit project license or upstream terms.
